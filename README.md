# Sales Data Analysis Using Python and Pandas

## Project Description
This project demonstrates how to combine Python file handling with Pandas to analyze sales transactions. It processes 30+ transactions stored in a raw text file and generates a structured sales report.

## Operations Performed
- Create and write sales transactions into `sales.txt`.
- Read data using Python file handling.
- Load data into a Pandas DataFrame.
- Calculate revenue for each transaction.
- Find total revenue and average order value.
- Identify the highest-value and lowest-value orders.
- Calculate product-wise revenue.
- Calculate city-wise revenue.
- Export processed data into a CSV file.

## Technologies Used
- Python
- Pandas
- VS Code

## Input and Output Files
- `sales.txt` – Raw sales transaction data.
- `sales_report.csv` – Processed sales report.

## Objective
To understand Python file handling, Pandas DataFrames, data manipulation, grouping, aggregation, and CSV export through a practical sales analysis project.
